# Cowork

There's no separate Cowork prompt. In the current desktop app, Cowork's global
instructions were folded into **Instructions for Claude** (Settings > Your Claude),
so `../system-prompt/system-prompt.md` drives both chat and Cowork.

If your app still shows **Settings > Cowork > Global instructions**, paste the same
`system-prompt.md` there.

Cowork also has **folder instructions** (Customize panel, per local folder) and
**project instructions**. When you write ones worth keeping, save them here as
`<folder-or-project>.md`.
