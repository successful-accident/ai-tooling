# ai-tooling

This repo is public. Never commit anything sensitive or work-related to it, in
files or in commit messages:

- No secrets: API keys, tokens, passwords, or the names of the keychain entries
  or variables that hold them.
- No work material: employer, client or customer names, internal hostnames,
  URLs, tenant or org IDs, and no work-specific skills, commands or instructions.
  Those belong in a private work repo.
- No personal details beyond the GitHub username.

Check the diff for these before every commit. If you're unsure whether something
counts, leave it out and ask. If something sensitive was already pushed, deleting
it in a new commit isn't enough because it stays in history: stop and tell the
user, since the fix is a history rewrite and a force-push.
